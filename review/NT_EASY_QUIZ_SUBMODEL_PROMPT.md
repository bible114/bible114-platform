# 신약일독 쉬운 퀴즈 하위 모델 출제 지시문

## 목표

신약일독의 지정 DAY 구간에 대해 초신자와 초등학생이 그날 본문을 한 번 읽고 바로 답할 수 있는 4지선다 문제를 하루 5개씩 만든다.

## 입력

- `src/data/read_schedules.json`의 `new_testament` 일정
- 지정 DAY의 실제 성경 본문
- 중복 회피용 `src/data/quiz/*.json`
- 기존 후보가 있으면 해당 `review/nt_easy_quiz_candidates_*.json`

## 출력 형식

```json
[
  {
    "day": 1,
    "date": "1-1",
    "range": "마 1장",
    "questions": [
      {
        "q": "마리아가 낳은 아기의 이름은 무엇인가요?",
        "choices": ["요한", "베드로", "바울", "예수"],
        "answerIndex": 3,
        "ref": "마태복음 1:21",
        "reviewStatus": "pending"
      }
    ]
  }
]
```

## 출제 규칙

1. 하루에 정확히 5문항, 선택지는 정확히 4개로 쓴다.
2. 정답은 `ref`의 지정 본문에 직접 나와야 한다.
3. 질문은 짧은 사실 확인형으로 쓴다. 인물, 장소, 행동, 말씀, 사건 결과를 우선한다.
4. 질문만 읽어도 무엇을 묻는지 분명해야 하며 부정형 질문은 쓰지 않는다.
5. 족보의 낯선 이름, 세부 숫자, 어려운 교리 용어, 장 전체 요약 문제는 피한다.
6. 오답 3개는 각 문항에 맞게 개별 작성한다. 다른 문항의 정답 목록을 섞어 넣지 않는다.
7. 네 선택지는 같은 종류와 문법 형태로 맞추고 정답이 길이·구체성만으로 드러나지 않게 한다.
8. 정답 위치는 하루에 최소 3개 위치를 사용하고 구간 전체에서 고르게 분산한다.
9. 같은 날 의미가 겹치는 질문을 만들지 않는다.
10. 기존 서비스 질문의 머리말만 빼거나 표현만 조금 바꿔 재사용하지 않는다. `이 이야기에서`, `이 장면에서`, `본문을 보면`, `그때`, `말씀 속에서` 같은 장식용 머리말도 쓰지 않는다.
11. `date`, `range`, `ref`는 일정과 실제 본문 범위를 벗어나면 안 된다.
12. 후보 파일만 수정하고 `src/data/quiz/*.json` 및 앱 연결 코드는 건드리지 않는다.

## 제출 전 자체 검수

- 질문과 정답이 정확히 대응하는가?
- 오답도 질문에 문법적으로 답이 되는 형태인가?
- 복수 정답으로 읽힐 가능성이 없는가?
- 평행본문의 다른 복음서 내용을 섞지 않았는가?
- 같은 날 5문항이 서로 다른 사실을 묻는가?
- 초등학생에게 낯선 단어는 더 쉬운 표현으로 바꿨는가?

마지막으로 아래 검사를 통과시킨다.

```bash
npm run validate:nt-easy
```

자동 검사 통과는 최종 승인이 아니다. 다른 하위 모델의 독립 사실 검수와 사용자 검수를 거쳐야 한다.
