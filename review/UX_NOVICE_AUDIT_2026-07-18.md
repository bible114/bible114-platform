# 컴맹 성도 관점 UX 점검 (2026-07-18, Claude)

모바일(375×812) 로컬 dev에서 첫 방문 → 로그인 → 교인 가입 → 공동체 등록(2단계 직전까지) → 게스트 읽기 완료 흐름을 실제로 밟아 확인했다. 운영 데이터 쓰기 없음(공동체 등록 최종 제출·교인 가입 제출은 하지 않음).

## 잘 되어 있는 것

- **성도용 가입 안내문 인쇄(QR)**: A4·어르신 큰 글씨·가입 4단계·입장코드 기입란. QR은 대표 주소로 통일하고 교회 검색 안내 (ChurchAdminView.jsx `printMemberGuide`).
- **관리자 매뉴얼 인쇄**: 대시보드/교인 관리/비밀번호 재설정/달란트 상점(창구판매 포함)/FAQ까지 책상 비치용으로 충분.
- 교회 이름 한 글자 검색 즉시 결과, "5초만에 빠른 시작"(카카오), 필수 동의 마스터 체크박스(실클릭 시 하위 4개 정상 전파 확인), 비밀번호 문의 모달(교회 관리자에게 안내), 혼자 읽어요(무소속) 경로, 게스트 모드 기록 경고와 "가입하고 기록 지키기" 전환 버튼.
- 공동체 등록 1→2단계 전환 시 스크롤 정상, 조직 구성에 "기본 조직 불러오기" 프리셋.

## 발견한 문제 (우선순위순)

### P1 — ✅ 전부 수정됨 (`86599a8`, 2026-07-18 사용자 지시. 광고는 제거하지 않고 하단 여백으로 해결)
1. **생년월일 형식 오류가 "등록되지 않은 사용자입니다"로 표시** — 교인 로그인에서 생년월일을 6자리(900101)로 넣어도 형식 안내 없이 미등록 사용자 오류. 실제 등록된 어르신이 자기 계정이 없다고 오해하는 1순위 시나리오. 8자리 형식 검증 문구 또는 6자리(YYMMDD) 자동 보정 필요.
2. **하단 고정 광고(카카오 애드핏)가 로그인 첫 화면의 "카카오로 시작" 버튼을 가림** — 모바일에서 스크롤 위치에 따라 주요 CTA와 겹침. 최소한 로그인·가입·공동체 등록 화면에서는 광고 숨김 권장. (iframe: t1.daumcdn.net/kas)
3. **"공동체 등록" 버튼을 눌러도 화면이 폼으로 이동하지 않음** — 히어로 아래에 폼이 렌더되지만 스크롤이 안 돼 "아무 일도 안 일어난 것"처럼 보임. scrollIntoView 필요.

### P2
4. 교인 가입의 **입장코드 입력칸이 password 타입** — 어르신이 입력한 4자리 코드를 눈으로 확인 못 함. 보기 토글 또는 평문 표시 권장.
5. 로그인 오류 문구의 전문용어 — "개인 계정으로 전환하셨다면 첫 화면 '시작하기'에서 로그인해주세요"는 일반 성도에게 무의미. 실패 원인별(이름/생년월일 불일치 vs 비밀번호)에 가까운 안내로.
6. **카카오 시작 버튼에 접근성 라벨 없음** (빈 button) — 스크린리더 사용자에게 안 읽힘.
7. 첫 화면 통계 "오늘 읽은 성도"가 `—`로 표시 — 0이면 0으로, 로딩이면 로딩 표시.
8. "기존 회원 로그인(이름으로)" 진입 후에도 "시작하기·개인 계정 로그인" 카드가 먼저 보여, 이름 입력까지 교회 검색·선택 단계가 한 겹 더 있음(동선은 맞으나 첫 카드가 시선을 뺏음).

### 참고 (설계상 의도, 안내 필요)
- 가입 안내문의 입장코드는 코드 원문 미저장 정책 때문에 **관리자가 세션 중 코드를 변경/입력한 직후 인쇄할 때만 자동 포함**, 아니면 빈칸에 손글씨. 관리자 매뉴얼에 이 순서를 한 줄 더 명시하면 좋음.
- 게스트 모드는 퀴즈·달란트 없음(가입 유도 동선은 존재).

## 2차 — 실사용(매일 루프) 점검 (같은 날 추가)

로그인 후 매일 반복하는 흐름(접속 → 듣기/읽기 → 완료 → 퀴즈 → 달란트 → 상점 수령)을 게스트 UI + 회원 전용 코드로 점검했다.

### 이미 잘 갖춰진 것
- **앱 내 12단계 화면 투어**: 대시보드 헤더 ❓ "읽는 방법 도움말" → 안내 모달 → 화면 투어(버전 바꾸기, 연속 읽기 경고, 점수/업적, 시작일 조정, 달력, 좌우 날짜 이동, 글씨 크기 기억, 듣기+속도, 절 번호 탭 낭독, 읽기 완료, 메모). 로그인 전에도 가짜 데이터 데모 체험(DemoTour) 제공.
- TTS 인앱 브라우저 대응: 네이버/구글 앱은 미지원 안내, 카톡 인앱은 낭독 시 외부 브라우저 안내.
- 퀴즈 카피 명확: "이 DAY는 최대 2번 도전", "퀴즈 달란트는 하루 첫 정답에만 적립", 종료 후 정답·해설 다시 보기.
- 상점: "구매한 상품은 교회에서 직접 받아요" 고정 안내 + 구매 완료 토스트 + 대기/수령 완료 배지. 앱이 어려운 어르신은 관리자 창구판매로 우회 가능.
- 게스트 → 가입 시 기기 기록 이전 준비(guestMigrationPreview).

### 불편·공백 (실사용)
1. **[가장 큼] 매일 다시 들어오는 길 안내가 없음** — PWA manifest는 있지만 "홈 화면에 추가" 안내가 앱에도 인쇄물에도 없다. 어르신은 매일 카톡 대화방에서 링크를 다시 찾는다. 제안: ① 가입 안내문(A4)에 "홈 화면에 추가" 3단계(아이폰 사파리/안드로이드 크롬 각각) 추가, ② 앱 내 1회성 안내 배너.
2. **성도용 "매일 사용법" 인쇄물 공백** — 가입 안내문은 가입·로그인·읽기완료까지만 다룬다. 퀴즈 규칙(2번 도전·하루 1회 적립), 달란트 적립(첫 읽기 10+연속 보너스), 상점 수령 절차, 듣기 기능은 게시판용 안내가 없다. 관리자 매뉴얼처럼 "성도용 매일 이렇게 해요" A4 1장 인쇄 버튼 제안.
3. **성도용 일반 문의 채널 없음** — 비밀번호 문의 모달은 있으나 그 외 문제(영상 안 나옴, 달란트 이상, 수령 문제)는 문의 경로가 화면에 없다. 도움말 모달에 "막히면 우리 교회 관리자(선생님)에게 말씀해주세요" 한 줄 추가 제안.
4. **밀린 성도의 날짜 혼동 가능성** — 본문 제목에 원 일정 날짜가 박혀 있어("7월 18일 / 왕상 6-7장"), 며칠 밀린 성도는 실제 날짜와 다른 날짜가 보인다. 시작일 조정 기능은 있으나 어르신 혼자 쓰기 어려움 — 관리자 매뉴얼 FAQ에 "날짜가 안 맞는대요 → 시작일 조정" 항목 추가 제안.
5. 연속 읽기 끊김: 투어에 "하루 건너뛰면 0" 경고는 있으나, 끊긴 다음 날 위로/재동기 문구가 있는지는 미확인(관찰 항목).
6. 하단 고정 광고는 P1-2 수정으로 최하단 콘텐츠 가림은 해소됐지만, 본문 스크롤 중 지나가는 줄을 덮는 것은 고정 배너의 본질상 남는다(관찰).

## 검증 도구 메모
- form_input으로 체크박스를 켜면 React 상태에 반영되지 않는 가짜 체크가 됨 — 브라우저 검증 시 실클릭 필요 (이번 점검에서 마스터 동의 "버그"로 오인했다가 실클릭으로 정상 확인).
