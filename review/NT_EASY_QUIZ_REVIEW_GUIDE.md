# 신약일독 쉬운 퀴즈 검수 안내

## 현재 상태

- 이 폴더의 후보는 **검수 대기 자료**입니다.
- 실제 서비스의 문제 파일은 아직 바꾸지 않습니다.
- 전체 범위: 신약일독 Day 1~365, 하루 5문항, 총 1,825문항입니다.

## 검수 화면 사용

1. `NT_EASY_QUIZ_REVIEW.html`을 브라우저로 엽니다.
2. 시작 DAY와 끝 DAY를 좁혀 하루씩 확인합니다.
3. 각 문항에서 `승인`, `수정 필요`, `제외`를 선택하고 필요하면 수정 의견을 적습니다.
4. 검수를 마치거나 다른 기기에서 이어갈 때 `검수 결과 내보내기`로 JSON 파일을 보관합니다.

선택한 상태와 의견은 같은 브라우저에 자동 저장됩니다. 후보 JSON 원본은 검수 화면에서 직접 바뀌지 않습니다.

## 검수 기준

각 문항을 아래 순서로 확인합니다.

1. 초신자나 초등학생이 그날 본문을 한 번 읽고 답할 수 있는가?
2. 정답이 근거 구절에 직접 나오는가?
3. 질문과 선택지가 짧고 쉬운가?
4. 오답 셋이 같은 종류이면서도 정답과 분명히 구별되는가?
5. 족보의 낯선 인물, 정확한 숫자, 어려운 교리 용어를 묻지 않는가?
6. 같은 날 다섯 문제가 사실상 같은 질문을 반복하지 않는가?

## 판정 방법

- 그대로 사용 가능: `reviewStatus`를 `approved`로 변경
- 수정 필요: `reviewStatus`를 `revise`로 변경하고 `reviewNote`에 이유 작성
- 사용하지 않음: `reviewStatus`를 `rejected`로 변경하고 `reviewNote`에 이유 작성

자동 검증 명령:

```bash
npm run validate:nt-easy
```

추가 구간을 하위 모델에 맡기거나 재출제할 때는 `NT_EASY_QUIZ_SUBMODEL_PROMPT.md`의 지시문을 그대로 사용합니다.

검수 완료 후에만 신약일독 전용 문제 묶음으로 앱에 연결합니다. 기존 일년일독 퀴즈에는 영향을 주지 않습니다. 자동 검사를 통과해도 성경 내용과 표현에 대한 최종 검수는 필요합니다.
