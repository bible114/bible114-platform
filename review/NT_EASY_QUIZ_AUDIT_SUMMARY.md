# 신약일독 쉬운 퀴즈 통합 검수 요약

## 결과

- 범위: Day 1~365
- 문항: 하루 5문항, 총 1,825문항
- 대상: 초신자·어린이
- 자동 검사: 오류 0건, 경고 0건
- 하위 모델 독립 교차검수: 잔여 확실한 문제 0건, 검수 후보로 승인 가능
- 실제 서비스 반영: 아직 하지 않음

## 출제·검수 방식

1. 세 구간으로 나눠 하위 모델이 후보를 출제했다.
2. 작성에 참여하지 않은 하위 모델이 사실, 근거 구절, 질문·정답 대응, 복수정답, 난이도, 선택지 품질을 교차검수했다.
3. 기존 문제의 머리말만 제거하거나 장식용 문구만 붙인 재사용 문항은 폐기하고 다시 출제했다.
4. 다른 문항의 정답을 오답으로 대량 섞는 방식은 폐기하고 문항별 오답을 다시 작성했다.
5. 교차검수 잔여 지적을 수정한 뒤 같은 검수 모델이 재확인했다.

구간별 상세 기록:

- `nt_easy_audit_001_122.md`
- `nt_easy_audit_123_244.md`
- `nt_easy_audit_245_365.md`

## 자동 검사 범위

- 365일 일정의 날짜·본문 범위 일치
- 하루 정확히 5문항, 문항당 선택지 4개
- 정답 위치·근거 구절 범위·중복 선택지
- 부정형, 숫자·족보 암기형, 장 요약형, 어려운 교리 용어
- 기존 서비스 질문 완전 일치와 머리말만 바꾼 재사용
- 장식용 머리말과 다른 정답을 이용한 전역 오답 셔플

검사 명령:

```bash
npm run validate:nt-easy
```

## 사용자 검수

`NT_EASY_QUIZ_REVIEW.html`을 열어 DAY별로 정답과 근거 구절을 확인하고 `승인`, `수정 필요`, `제외`를 선택한다. 결과는 `검수 결과 내보내기`로 저장한다.

사용자 검수가 끝나기 전에는 후보를 앱이나 기존 `src/data/quiz/*.json`에 연결하지 않는다. 이 후보는 기존 일년일독 문제에 영향을 주지 않는다.
